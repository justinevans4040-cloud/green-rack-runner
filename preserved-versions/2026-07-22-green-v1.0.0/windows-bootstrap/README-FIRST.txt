GREEN RACK RUNNER — WINDOWS INSTALLER

Double-click INSTALL-GREEN-RACK-RUNNER.cmd.

The installer downloads the verified official Windows desktop runtime, installs
Green Rack Runner for the current Windows user, creates Desktop and Start Menu
shortcuts, registers it in Windows Installed Apps, and opens the application.

No administrator permission is required. Internet access is required during
installation for the verified desktop runtime download.
