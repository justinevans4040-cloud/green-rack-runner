# Bar-night companion pack for Green Rack Runner Functional V2

| Script / file | Desktop shortcut | Job |
|---------------|------------------|-----|
| `RACK_RUNNER_BAR_FOCUS.ps1` | Rack Runner BAR FOCUS | Stop noisy apps; focus Functional V2 |
| `WATCH_PLAYER_ALERTS.ps1` | Rack Runner Player Alerts | Watch sync; popup on Called / Dispute / Unpaid |
| `START-RACK-RUNNER-TV.bat` | Rack Runner TV | TV helper page + launch Functional V2 |

Source of truth app: installed Green Rack Runner (`%LOCALAPPDATA%\Programs\Green Rack Runner`).
Sync alerts poll `http://127.0.0.1:8765/api/sync` (Electron sync server).
